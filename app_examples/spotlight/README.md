# Argui Spotlight

This product-shaped example combines the global shortcut, tray lifecycle,
desktop backdrop and implicit animation APIs. Closing the native window hides
it without stopping the process; `Cmd/Ctrl+Space` restores and focuses it, and
the tray menu supplies explicit show and quit actions.

The panel requests the operating system's glass material. Argui automatically
uses a lightly opaque fallback when native blur is unavailable. The browser
build uses that fallback over the supplied gradient page. Filtering retargets
stable `AnimatedContainer` rows, colors, radii and transforms without a custom
animation loop.

Run the native application from the repository root:

```sh
cargo run --manifest-path app_examples/Cargo.toml -p argui-example-spotlight
```

On Wayland, approve `Ctrl+Space` in the desktop portal the first time it is
requested. A direct development run temporarily installs the matching
`dev.argui.spotlight.desktop` entry and repairs stale entries previously
generated by this example, so the portal can identify the unbundled binary.

Check and build the browser version:

```sh
cargo check --manifest-path app_examples/Cargo.toml \
  -p argui-example-spotlight --target wasm32-unknown-unknown
wasm-pack build app_examples/spotlight --target web --dev --out-dir web/pkg
python3 -m http.server --directory app_examples/spotlight/web 8000
```

Open `http://localhost:8000`. Browsers cannot register operating-system global
shortcuts or tray icons, but the same translucent animated search UI runs on
the WebAssembly renderer.

The browser scenario must run on the repository's private display:

```sh
CHROME_PATH=/path/to/chrome \
SPOTLIGHT_URL=http://127.0.0.1:8000/ \
./scripts/linux-hidden-display.sh \
  python3 app_examples/spotlight/tests/browser.py
```

The native shortcut lifecycle can also be exercised on the private X11 display
after building the application:

```sh
target_dir="$(cargo metadata --manifest-path app_examples/Cargo.toml \
  --no-deps --format-version 1 | jq -r .target_directory)"
ARGUI_TEST_BACKEND=x11 ./scripts/linux-hidden-display.sh \
  python3 app_examples/spotlight/tests/native_shortcut.py \
  "$target_dir/debug/argui-example-spotlight"
```
